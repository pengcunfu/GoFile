# 📁 局域网文件传输助手

一个简单高效的基于 Go + Web 的局域网文件传输工具，支持文件上传、下载和列表管理。

## ✨ 功能特性

- 📤 **文件上传** - 支持拖拽上传和点击选择，可批量上传
- 📥 **文件下载** - 一键下载任意文件
- 📋 **文件列表** - 实时显示服务器上的所有文件
- 🗑️ **文件删除** - 支持在线删除不需要的文件
- 🎨 **美观界面** - 现代化的响应式设计，支持移动端
- 🔒 **局域网传输** - 在同一局域网内快速传输文件
- ⚡ **高速传输** - 基于原生 Go 实现，传输速度快

## 🚀 快速开始

### 环境要求

- Go 1.16 或更高版本
- 现代浏览器（Chrome、Firefox、Edge 等）

### 安装运行

1. **克隆或下载项目**

```bash
cd GoFile
```

2. **运行服务器**

```bash
go run main.go
```

3. **访问应用**

打开浏览器访问：
- 本机访问：`http://localhost:8080`
- 局域网访问：`http://你的IP地址:8080`

查看本机 IP 地址：
- Windows: `ipconfig`
- Linux/Mac: `ifconfig` 或 `ip addr`

## 📖 使用说明

### 上传文件

1. **点击上传** - 点击"选择文件"按钮，选择要上传的文件
2. **拖拽上传** - 直接将文件拖拽到上传区域
3. 支持同时选择多个文件进行上传

### 下载文件

在文件列表中找到要下载的文件，点击"⬇️ 下载"按钮即可。

### 删除文件

点击文件右侧的"🗑️ 删除"按钮，确认后即可删除文件。

### 刷新列表

点击"🔄 刷新"按钮重新加载文件列表。

## 🔧 配置说明

### 修改端口

编辑 [main.go](main.go#L17) 文件：

```go
const port = ":8080"  // 修改为你想要的端口
```

### 修改上传目录

编辑 [main.go](main.go#L16) 文件：

```go
const uploadDir = "./uploads"  // 修改为你想要的目录
```

### 修改文件大小限制

编辑 [main.go](main.go#L90) 文件：

```go
err := r.ParseMultipartForm(100 << 20)  // 100 << 20 表示 100MB
```

## 🛡️ 安全注意事项

1. **局域网使用** - 本工具设计用于局域网文件传输，不建议直接暴露到公网
2. **文件验证** - 当前版本不包含文件类型验证，请谨慎上传和下载文件
3. **数据备份** - 上传的文件存储在 `uploads` 目录，请定期备份重要文件
4. **访问控制** - 如需添加访问控制，请自行实现身份验证功能

## 🎯 API 接口

### 获取文件列表
```
GET /api/files
```

### 上传文件
```
POST /api/upload
Content-Type: multipart/form-data
```

### 下载文件
```
GET /api/download/{filename}
```

### 删除文件
```
DELETE /api/delete/{filename}
```

## 🐛 常见问题

**Q: 无法访问服务？**
- 检查防火墙设置
- 确认端口是否被占用
- 查看本机 IP 地址是否正确

**Q: 上传大文件失败？**
- 修改 main.go 中的文件大小限制
- 检查磁盘空间是否充足

**Q: 中文文件名乱码？**
- 确保浏览器编码设置为 UTF-8
- 本程序已对中文文件名进行优化
